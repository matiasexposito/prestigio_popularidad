# La app

La app publicada vive en [`diseno/prototipos/prototipo_conjunto/`](../diseno/prototipos/prototipo_conjunto/), que es la carpeta que se sube a Vercel. Es la versión conjunta, la final. No se copia acá para no tener dos versiones del mismo código.

**Publicada en:** https://pyp-ashy.vercel.app

Para publicar una versión nueva, desde esa carpeta: `vercel deploy --prod`.
